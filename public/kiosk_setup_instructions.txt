מדריך התקנה, הקשחה והפעלה של אפליקציית הטאבלט (CartKiosk) למצב קיוסק הרמטי
=============================================================================

מדריך זה מיועד למנהל המערכת ומפרט את השלבים להתקנת האפליקציה בטאבלטים של העגלות והפיכתם לעמדת קיוסק נעולה לחלוטין.
בסיום תהליך זה, הטאבלט יינעל בצורה כזו שלא ניתן יהיה לצאת מהאפליקציה בשום אופן (מחוות, כפתור בית, כפתור חזור וסרגל ההתראות חסומים לחלוטין), והדרך היחידה להסירה או לגשת להגדרות תהיה באמצעות חיבור למחשב הניהול שלכם.

שלב א': הכנת הטאבלט הפיזי (פעולה חד-פעמית)
----------------------------------------
1. היכנס להגדרות הטאבלט -> אבטחה (או מסך נעילה).
2. הגדר קוד נעילה (PIN או סיסמה קשיחה) למכשיר. 
   * חשוב: זהו קוד נעילת המערכת של הטאבלט הפיזי (למשל 1234 או סיסמה מורכבת). אל תגלה קוד זה לתלמידים!
3. ודא כי בהגדרות הנעילה האבטחה מופעלת האפשרות "נעל רשת ואבטחה" (או "דרוש קוד נעילה לצורך כיבוי או הפעלה מחדש").

שלב ב': הפעלת מצב מפתחים ו-ADB
-----------------------------
1. היכנס להגדרות הטאבלט -> אודות המכשיר (About Tablet).
2. לחץ 7 פעמים ברציפות על "מספר גרסת ייצור" (Build Number) עד להופעת ההודעה: "כעת אתה מפתח!" (Developer mode enabled).
3. חזור לתפריט ההגדרות הראשי -> היכנס ל"אפשרויות מפתח" (Developer Options).
4. הפעל את האפשרות: "ניפוי באגים ב-USB" (USB Debugging / ADB).

שלב ג': התקנת האפליקציה והענקת הרשאות ניהול (Device Owner)
---------------------------------------------------------
1. הורד את קובץ האפליקציה (CartKiosk.apk) מאתר הניהול והתקן אותו בטאבלט.
2. חבר את הטאבלט למחשב הניהול שלך באמצעות כבל USB.
3. במסך הטאבלט תקפוץ הודעה: "האם לאפשר ניפוי באגים ב-USB ממחשב זה?".
   * הצעד החשוב ביותר: סמן בתיבת הסימון [x] "אפשר תמיד ממחשב זה" (Always allow from this computer) ולחץ על "אפשר" (Allow).
   * שלב זה מאשר קבועה את מחשב הניהול שלך מול הטאבלט, ומאפשר חיבור עתידי מיידי ללא חלונות קופצים.
4. פתח חלון CMD או PowerShell במחשב שלך (ודא שכלי ה-ADB מותקנים במחשב).
5. הרץ את פקודת הרישום הבאה כדי להגדיר את האפליקציה כבעלת המכשיר (Device Owner) ברמת הקרנל:

3. adb shell dpm set-device-owner com.example.cartkiosk/.KioskDeviceAdminReceiver

6. (אופציונלי - העמדת הטאבלט הפוך ב-180° כשהמצלמה למטה):
   * כדי לאפשר לסיבוב האוטומטי ב-180° לפעול במכשירים שבהם הוא כבוי כברירת מחדל:
     adb shell settings put system accelerometer_rotation 1
   * או כדי לנעול קשיח את הטאבלט ב-180° הפוך באופן קבוע (מצלמה למטה):
     adb shell settings put system accelerometer_rotation 0
     adb shell settings put system user_rotation 2

7. נתק את כבל ה-USB ופתח את אפליקציית הטאבלט (CartKiosk).
   * הטאבלט יינעל מיידית בצורה הרמטית לחלוטין! מקש הבית, יישומים אחרונים, כפתור החזור וסרגל ההתראות יושבתו לחלוטין.

שלב ד': עבודה שוטפת בבית הספר
---------------------------
* הטאבלט נעול קבוע על האפליקציה. 
* במידה ותלמיד ינסה לבצע כיבוי או הפעלה מחדש של המכשיר באמצעות לחצן הכיבוי הפיזי, מערכת ההפעלה Android תעצור אותו ותדרוש את הזנת קוד הנעילה (PIN/סיסמה) של הטאבלט שהגדרת בשלב א'.
* בעת הפעלה מחדש (לאחר הזנת הקוד התקין), הטאבלט עולה ישירות לתוך האפליקציה הנעולה כשהיא נקייה, ומאפשר למורה להגדיר עגלה חדשה. ברגע שהעגלה נבחרה, הטאבלט יינעל מחדש על ממשק ההפעלה שלה ללא יכולת חזרה אחורה.

שלב ה': שחרור הטאבלט או הסרת האפליקציה (מנהל המערכת בלבד)
-----------------------------------------------------------
כאשר תרצה להסיר את הנעילה או לעדכן את האפליקציה כמנהל מערכת, בצע את השלבים הבאים:
1. חבר את הטאבלט באמצעות כבל USB למחשב הניהול שלך (זה שאושר קבועה בשלב ג').
2. פתח שורת פקודה במחשב והרץ את הפקודה לביטול סמכות הניהול של האפליקציה:

   adb shell dpm remove-active-admin com.example.cartkiosk/.KioskDeviceAdminReceiver

3. לאחר מכן, הרץ את פקודת ההסרה כדי למחוק את האפליקציה מהמכשיר:

   adb uninstall com.example.cartkiosk

   * הטאבלט ישתחרר מיידית ויחזור למצב הרגיל והפתוח של אנדרואיד!
=============================================================================
